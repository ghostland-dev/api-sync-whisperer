# API Sync

Tool to configure and monitor synchronisation between APIs.

## Features

- Supabase authentication
- Connection configuration
- Sync status dashboard

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Supabase

## Getting Started

```bash
git clone https://github.com/ghostland-dev/api-sync-whisperer.git
cd api-sync-whisperer
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
